# Ultimate Remastered

created by Bedcraft

## Overview

A community-created Minecraft 1.4.7 modpack aiming to be similar to FTB Ultimate, with new content and without the bugs, crashes, and exploits.

Minecraft 1.4.7 has a variety of mods that weren't updated to later versions or had drastic changes made to them.
It contains the "classic" version of IndustrialCraft 2 with solid UU-Matter, GregTech 2 when it was still an IC2 addon, the original logic mod RedPower2, among other famous mods such as BuildCraft, Thaumcraft 3, Factorization, Forestry, Railcraft, and Applied Energistics 1.

FTB Ultimate was the flagship modpack of its time, including most well-established 1.4.7 mods.
The modpack hasn't been updated since May 2013, but there have been numerous "retro-modding" efforts since then to improve the experience on this ancient Minecraft version.

The pack was mostly designed for our public server, Bedcraft.
We have hosted the original FTB Ultimate since its release in 2013 and switched to our own modpack to further improve the experience for our players.

## Installation

The pack must be played through PrismLauncher and comes with an auto-updater.
It is shipped as a ZIP file for PrismLauncher.

1. Download and install [PrismLauncher](https://prismlauncher.org/)
2. Click `Add Instance` in the top left corner
3. Select `Import` in the menu on the left and paste [this link](https://ultrem.bedcraft.uk/client/Ultimate%20Remastered.zip) into the text field.
4. Launch the pack. The content will automatically download. Optional mods can be selected on first launch.
5. If you want/need OptiFine: Select the instance, click on `Edit` on the right side of the main window. Select `Version` in the instance window and click on the OptiFine checkbox.

The Bedcraft server is preconfigured in the Multiplayer menu.

If you want to host your own server, download the [server zip](https://ultrem.bedcraft.uk/server/ultimate-remastered.zip) and execute the `run.sh` script.

## Changes to FTB Ultimate

### New content mods

- **ChiselRetro**: Chisel backport
- **[DartCraft](https://web.archive.org/web/20130509170724/http://www.minecraftforum.net:80/topic/1686840-151-dartcraft-beta-0111/)**: A magic mod that became famous between 1.5.2 and 1.6.4
- **LogisticsPipes**: Automation addon for BuildCraft pipes
- **[rpcDrive](https://modrinth.com/mod/rpcdrive)**: ComputerCraft / RedPower2 computer interoperability
- **[OpenCCSensors](https://web.archive.org/web/20240706020601/http://computercraft.info/wiki/OpenCCSensors)**: Additional peripherals for ComputerCraft
- **Ruins**: Worldgen structures that contain loot and traps

### Fixes, Backports, QoL changes

This list is not exhaustive; notable changes are listed here.
Many fixes have been created by [Exa](https://exa.y2k.diy/) for [Rewind Upsilon](https://rewindmc.com/).
Without their work this project wouldn't be possible.

- **BlockHelper**: WAILA and ModNameTooltip backport
- **BuildCraft**: Clay pipes and 1.5+ Autarchic Gate features
- **CC: Tweaked**: Backports for ComputerCraft
- **[Ears](https://ears.y2k.diy/)**: Modern skin backport with extra skin features
- **Mouse Tweaks**: Item dragging tweaks in inventories (the vanilla RMB behaviour has also been backported and can be enabled in the UpsilonFixes config)
- **NEI Addons**: Bee breeding in NEI and shift-click support for the ME Pattern Encoder
- **RetroTweaker**: MineTweaker3 backport
- Sprint key when pressing `CTRL`, linked to the IC2 Boost Key
- macOS and Apple Silicon compatibility patches
- RedPower can interact with BuildCraft pipes
- The fire in the Factorization Wrath Forge lasts forever
- Project Table "Clear" button and better NEI shift-click support
- Chat message length is increased to match modern versions
- More ExtrabiomesXL biomes
- EE3 Minium Stone recipes don't break
- Tesseracts keep their frequency when broken
- Item pickup on XReliquary's Coin of Fortune works reliably
- Ultimate Solar Helmet will consume filled tin cans like the Quantum Helmet would
- Buffed GregTech's Jack Hammers
- MiscPeripherals Bee Analyzer can read both primary and secondary alleles
- Fixed water whirlpools (1.5 water fill backport) ([MC-916](https://bugs.mojang.com/browse/MC-916))
